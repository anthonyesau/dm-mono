# Technical symbol extension generator

`build.py` adds the technical-symbol glyphs and their OpenType features to
both Glyphs sources in `source/`. It works from the original outlines and is
idempotent: glyphs it generated earlier (tagged with a note in the glyph
info) are replaced, and it refuses to overwrite any glyph a person drew.

```sh
pip install glyphsLib
python tools/extend/build.py          # updates source/*.glyphs
cd source && sh build.sh              # builds exports/*.ttf
python tools/extend/specimen.py       # optional: docs/technical-symbols.png
```

* `geo.py`: outline primitives (rings, arcs, strokes, outlined polygons,
  arrows). Every primitive gives the same point structure for any stroke
  weight, so the Light and Medium masters stay compatible and Regular
  interpolates. It also has the weight-compensated scaler used for small
  figures, and the italic slant (10°, around y = 248, as in the italic
  masters).
* `recipes.py`: one function per glyph. Shapes are drawn upright, centred
  in the 600-unit cell on the math axis (y = 350), using the stroke of the
  existing `minus` / `plus`. Italic masters get the same drawing, slanted.
* `build.py`: per-master parameters, glyph creation and feature code.

Small figures (fractions, superiors, balloons) and the circled letters
are scaled-down regular glyphs thickened back to the right stem weights.
The scaling parameters were fitted so the generated ² ³ ⁴ and the small
2 3 4 land on top of the designer's hand-drawn ones.

Fractions are diagonal: numerator high and left, denominator low and
right, either side of a steep slash (`fraction.inline`), all in one cell.
Their figures are 400 units tall, slightly condensed, and the zero drops
its slash. The `frac` feature uses the same figures (`.numr`, `.dnom`) with
a wider slash (`fraction.diag`) that has a cell to itself. The recipes
replace the designer's stacked ½ ¼ ¾ (listed in `REPLACES`); the
originals are in git history.

New glyphs carry the note "Generated by tools/extend/build.py". Edit them
in Glyphs as usual, but remove that note first, or the next run of
`build.py` will replace them.
